# AWS EKS 웹서비스 재배포 · 운영 자동화

개발자에게 전달받은 웹소스를 초기 테스트한 뒤, 자동화 환경에 배포하고 운영·복구까지 확인한 팀 프로젝트입니다.

## 노션에 가져오는 방법

1. 전달받은 노션용 ZIP을 압축 해제합니다.
2. 노션의 가져오기에서 Markdown 파일을 선택해 각 페이지를 가져옵니다.
3. 이 홈 페이지 아래로 나머지 페이지를 배치합니다. 파일명 링크가 자동 연결되지 않으면 가져온 노션 페이지 링크로 바꿉니다.
4. 검증 캡처는 해당 페이지에 추가합니다. AWS 계정·이메일·토큰·Secret·state 등 공개 범위를 먼저 확인합니다.

이번 복사는 코드와 문서 정리 작업입니다. 이전 실습 기록과 이번 로컬 검사 결과를 구분했고, AWS 실행·실배포는 수행하지 않았습니다. 노션 계정에 직접 게시한 것은 아닙니다.
