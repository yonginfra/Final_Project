## 실행한 범위

- Terraform 초기화는 `-backend=false -lockfile=readonly`로 provider·로컬 모듈 준비만 했습니다. 원격 state에는 연결하지 않았습니다.
- Terraform test는 `mock_provider`와 가짜 remote state를 사용했습니다. 테스트의 plan/apply는 모의 실행이며 실제 AWS plan/apply/destroy가 아닙니다.
- Python 회귀 검사는 가짜 API·mock 명령을 사용했습니다. 테스트 출력의 삭제·복원 메시지도 가짜 API 시나리오입니다.
- 이번 작업에서 AWS CLI, 실제 Kubernetes endpoint, 실제 ECR 게시, Terraform 실배포는 실행하지 않았습니다.
- 새 저장소의 AWS 게시·배포 검증 활성화 변수는 미설정 상태로 확인했습니다. 일반 GitHub CI와 실제 AWS 작업을 구분합니다.

본인 계정에서의 state·DNS·인증서·이미지 존재 여부, IAM 역할 인증, 새 ECR 게시, 실제 앱 배포·승인·CodeBuild 실행·메일 수신은 이번 검사 대상이 아닙니다. 이전 환경의 실습 결과를 이번 복사본의 성공 결과로 대체하지 않습니다.
