# 구성도와 아이콘 출처

`architecture.png`와 `architecture.svg`는 현재 Final_Project 코드에 맞춰 새로 구성했습니다. 이전 이미지와 SVG는 `architecture-legacy-20261015.*`로 보존했습니다. 원본 팀 저장소의 배치·색감을 참고했으며 NAT 2개, RDS Multi-AZ, 승인 PR, ESO와 주문 이메일 처리 등 최종 구성을 반영했습니다.

아이콘은 기존 프로젝트 문서 작업에서 확보한 PNG 자산을 재사용했습니다. AWS 서비스는 mingrammer/diagrams의 AWS 리소스, 일부 브랜드는 Simple Icons, 사람과 경보 표시는 Lucide 자산입니다. SVG에는 아이콘 바이트를 포함해 외부 다운로드 없이 볼 수 있습니다. GitHub와 노션에는 PNG를 사용합니다.
